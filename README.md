# IELTS Listening Practice Test 10D (Cambridge IELTS 19, Test 4)

Post-midterm listening batch · LSC 0316 · Designed by: Nazila Motahari

## Upload to GitHub Pages
1. Unzip. Keep `index.html` and the `audio` folder together.
2. Create a new public repository (e.g. `IELTS-Listening-Test-10D`).
3. Add file → Upload files → drag in `index.html`, `README.md` and the whole `audio` folder → Commit.
4. Settings → Pages → Branch: `main`, folder `/ (root)` → Save.

Audio files must be named `part1.mp3` … `part4.mp3` (lower case). The app looks in `audio/` first, then in the repository root.
